# Architecture Decision Records

ADRs preserve why durable technical decisions were made.

## Naming

`ADR-XXXX-short-title.md`

## Status

-   Proposed
-   Accepted
-   Superseded
-   Deprecated

## Template

``` md
# ADR-XXXX — Title

## Status
Proposed

## Context
What problem requires a durable decision?

## Decision
What was decided?

## Alternatives Considered
What realistic alternatives were evaluated?

## Consequences
Positive and negative consequences.

## References
Related SDDs, requirements, or ADRs.
```

Never rewrite an accepted historical ADR to hide a changed decision.
Create a new ADR and mark the old one Superseded.
