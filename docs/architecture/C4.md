## Level 2 --- Containers

``` mermaid
C4Container
title Personal Finance Platform - Containers

Person(user, "User")

System_Boundary(system, "Personal Finance Platform") {
  Container(web, "Web App", "Expo / React Native Web / TypeScript", "Responsive financial management and analytics.")
  Container(mobile, "Mobile App", "Expo / React Native / TypeScript", "Android/iOS financial management and quick capture.")
  Container(api, "Application API", "Node.js / Fastify / TypeScript", "Use cases, authorization, domain orchestration, audit, API contract.")
  ContainerDb(db, "Relational Database", "SQL", "Financial, identity-reference, permission, and audit data.")
  Container(storage, "Object Storage", "Managed storage", "Future receipts and document attachments.")
}

Rel(user, web, "Uses")
Rel(user, mobile, "Uses")
Rel(web, api, "HTTPS/JSON")
Rel(mobile, api, "HTTPS/JSON")
Rel(api, db, "Reads/Writes")
Rel(api, storage, "Future document storage")
```

The Web App and Mobile App containers are built from the same Expo
codebase (`apps/client`, ADR-0001) and deployed as separate artifacts:
a static Web build and native Android/iOS builds.

Identity is handled by Better Auth inside the Application API
(ADR-0007); there is currently no external Identity Provider. The
external Identity Provider in the context diagram represents future
Google and Apple sign-in.

Implemented as of SDD-002: Web App and Mobile App with sign-up,
sign-in, and a protected area; Application API with authentication and
`GET /me`; Relational Database (PostgreSQL) holding authentication
data. Object Storage does not exist yet.

## Initial component focus

For `v0.1.0`, component-level documentation should focus only on modules
actually introduced:

-   Identity integration;
-   Financial Space application/domain;
-   Classification application/domain;
-   Transaction application/domain;
-   persistence adapters;
-   API controllers/routes;
-   Web/Mobile presentation required by the selected stack.

Do not document future components as if they already exist.
