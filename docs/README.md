# Project Documentation

This directory is the canonical documentation base for the financial
platform.

## Reading order for humans

1.  `product/PRODUCT-VISION.md`
2.  `product/REQUIREMENTS.md`
3.  `product/DOMAIN-RULES.md`
4.  `product/ROADMAP.md`
5.  `architecture/ARCHITECTURE.md`
6.  `architecture/C4.md`
7.  `engineering/ENGINEERING-GUIDELINES.md`
8.  `project/CURRENT-STATE.md`

## Reading order for agents

Agents must start from the repository-root `AGENTS.md`, then read
`project/CURRENT-STATE.md`, the active SDD, and only the relevant skills
and referenced documents.

## Documentation layers

-   **Vision:** where the product is going.
-   **Requirements:** accepted capabilities and constraints.
-   **Domain Rules:** authoritative financial behavior.
-   **Roadmap:** when capabilities should enter.
-   **Architecture:** how the system is structured.
-   **ADRs:** why important technical decisions were made.
-   **Engineering:** implementation standards.
-   **Current State:** what actually exists now.
-   **SDDs:** the bounded implementation increment to execute now.
-   **Changelog:** what was delivered.

Future vision must never be interpreted as current implementation scope.
