# SDD-016 --- v0.2.0 Release Validation

## Objective

Validate v0.2.0 end to end and release it without adding functionality.

## Dependencies

SDD-008 to SDD-015.

## Validate

Clean setup and migrations; all automated checks; browser journeys for
edit, delete/restore, status toggle, category management, filters,
balance snapshots and prompt, dashboard; isolation between users;
documentation accuracy.

## Definition of Done

Validation report recorded; release merged to `main` and tagged.
