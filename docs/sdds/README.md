# SDD Index

SDDs are bounded implementation specifications.

## Rules

-   One SDD should be small enough to implement, validate, and review
    independently.
-   An SDD must not silently expand into future roadmap scope.
-   Every SDD defines objective, scope, non-scope, dependencies,
    implementation guidance, acceptance criteria, and Definition of
    Done.
-   Agents must read `AGENTS.md` and `docs/project/CURRENT-STATE.md`
    before implementation.
-   After each SDD, update affected living documentation before starting
    the next one.
